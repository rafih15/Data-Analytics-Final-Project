# Data Analytics Final Project

A comprehensive Exploratory Data Analysis (EDA) and visualization project performed on the UAE Cancer Patient dataset using Python.

---

## 📌 Project Features

- **Data Cleaning & Preprocessing:** Date conversions, missing value handling, and feature engineering (BMI and Treatment Delay calculations).
- **Outlier Handling:** Handled extreme values using the **IQR Capping Method** without losing valuable patient records.
- **Non-Visual EDA:** Statistical data exploration including Mean, Median, Skewness, and Categorical Frequency Distribution tables.
- **Data Visualizations:**
  - **Univariate Analysis:** Age distribution histograms and Cancer Type frequency charts.
  - **Bivariate Analysis:** BMI comparison across genders and Treatment Outcome analysis.
  - **Multivariate Analysis:** Feature correlation heatmaps and multi-variable category plots.

---

## 🛠️ Tools & Libraries Used

- **Language:** Python
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn, Plotly Express

---

## 🚀 How to Run

1. Clone or download this repository.
2. Ensure you have Jupyter Notebook or Kaggle environment setup.
3. Place `_cancer_dataset_uae.csv` in the same project directory.
4. Open and run `Final_Project__.ipynb`.
